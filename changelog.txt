# 1.4.0
- Removed built-in changelog viewer — what's new overlay now shows a simple version notice
- Version string read directly from the DOM instead of changelog.txt

# 1.3.2
- Best streak (Reports) no longer breaks on zero-dose days
- load() now validates data structure, not just JSON syntax
- Fixed misleading refill tooltip on non-refill medications
- Visual theme resets to dark on data reset
- Saving a deleted medication now shows error instead of false confirmation
- Time-of-day chart no longer counts future doses
- Username resets to default on corrupted data fallback

# 1.3.1
- Ring chart colors fixed for light theme (unfilled arc uses var(--stroke))
- Sidebar, titlebar, and profile now have visible backgrounds in light theme on desktop
- App no longer crashes on corrupted localStorage data — falls back to sample data
- Next-dose widget shows "due now" when dose is due at 0 minutes, cleans up "in 1h 0min" display
- Streak no longer breaks on days with zero scheduled doses (e.g. weekends)
- Refill progress bar clamps to 0–100%; negative used count prevented
- Time input validation now rejects invalid hours (>23) and minutes (>59)
- "Reset all data" now clears missed-dose dismissals, Dropbox connection, and theme preference
- History page shows records with legacy unpadded time keys (e.g. 8:00)
- Donut chart shows neutral grey when there is zero data instead of full red
- Refill button on non-refill med cards uses consistent needsRefill() threshold
- Supply labels always show days left for meds with refill tracking enabled
- Opening modal for a deleted medication no longer crashes (silent close)
- Refill button on opt-out meds no longer silently enables refill tracking
- Various minor fixes: -webkit-backdrop-filter for Safari, btn hover transitions, strict equality, refillAlert range validation (1–365)

# 1.3.0
- Smart refill tracker — set pills per container and refill threshold per medication
- One-click refill button on medication cards and supply panel
- Usage progress bar shows how many pills used vs total in current container
- Refill stat card now respects per-medication refill thresholds
